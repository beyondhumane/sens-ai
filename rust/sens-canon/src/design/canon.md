## This game's design

This project keeps its game design in `Design/`: the pillars, the core loop and one file per mechanic. `Design/` is the source of truth about what game is being made. Read it whole with `design` and search it with `design_search` before you add or change gameplay.

- When your work adds or changes a mechanic, update its file in `Design/mechanics/`, with the pillars it serves and its status.
- When a request goes against a pillar, say so before writing anything, and let the person decide.
